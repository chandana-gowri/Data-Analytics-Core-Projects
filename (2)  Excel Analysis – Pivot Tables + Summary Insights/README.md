# Superstore Sales Pivot Analysis Report

## Aim
To analyze Superstore sales data using Pivot Tables and generate insights based on category-wise, segment-wise, and region-wise performance.

---

## Dataset Used
**Sample - Superstore Dataset**

This dataset contains sales transaction details such as category, sub-category, region, segment, sales, and profit.

---

## Files in This Folder
- **Sample - Superstore.csv** – Original dataset used for analysis
- **Pivot_Report.xlsx** – Pivot table report created in Excel
- **Pivot_Report.pdf** – Exported PDF report of pivot analysis
- **Insights.docx** – Document containing summarized business insights

---

## Work Done in This Task
- Imported the Superstore dataset into Excel
- Created Pivot Tables to analyze sales and profit performance
- Compared category-wise and segment-wise sales distribution
- Performed region-wise performance analysis
- Identified high-performing and low-performing regions
- Documented key findings and insights in report format

---

## Key Insights
- Technology category is the highest contributor to total sales
- Furniture category has good sales but relatively lower profit margins
- Office Supplies shows steady sales with healthier profit margins
- West region is the top-performing region in overall sales
- Central region shows moderate sales but lower profitability
- South region contributes the least sales and has growth potential
- Consumer segment dominates sales compared to Corporate and Home Office
- Some regions have high sales but weaker profit margins, indicating inefficiencies

---

## Tools Used
Microsoft Excel (Pivot Tables), MS Word, PDF Export

---

## Learning Outcome
This task helped in understanding how Pivot Tables can be used for quick business analysis and generating meaningful insights from large datasets.

---

## Conclusion
Pivot table analysis of Superstore sales data helped identify strong and weak performing categories, regions, and customer segments. The insights generated can support better decision-making and profitability improvement.
