# Netflix Dataset Cleaning & Preprocessing

## Aim
To clean and preprocess the Netflix Titles dataset by handling missing values, removing duplicates, and preparing a structured dataset for further analysis.

---

## Dataset Used
**Netflix Titles Dataset**

This dataset contains details of movies and TV shows available on Netflix, such as title, director, cast, country, release year, rating, duration, and listed genre.

---

## Files in This Folder
- **netflix_titles (raw dataset).csv** – Original raw dataset
- **cleaned_dataset.csv** – Cleaned dataset after preprocessing
- **Cleaned_dataset.xlsx** – Cleaned dataset saved in Excel format

---

## Data Cleaning Steps Performed
- Imported the raw dataset into Excel
- Checked dataset structure and identified missing values
- Removed duplicate records
- Filled or handled missing values in important columns
- Cleaned and formatted text-based columns
- Standardized data for consistency
- Exported the final cleaned dataset in CSV and Excel formats

---

## Tools Used
Microsoft Excel

---

## Learning Outcome
This task helped in understanding real-world dataset cleaning, handling missing values, and preparing structured datasets for data analysis.

---

## Conclusion
The Netflix dataset was successfully cleaned and organized into a proper format. The cleaned dataset is ready for further analysis, visualization, and reporting.
