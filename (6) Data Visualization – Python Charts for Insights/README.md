# Sales Data Visualization (Task 6)

## Aim
To perform data visualization on a sales dataset and understand sales trends using different graphical representations.

---

## Dataset Used
**Sales Data Sample Dataset**

The dataset contains sales transaction details such as product line, country, sales amount, quantity ordered, and order-related information.

---

## Files in This Folder
- **sales_data_sample (1).csv** – Original dataset used for visualization
- **Task6_Visualization.ipynb** – Jupyter Notebook containing visualization code and plots

---

## Visualizations Performed
- Sales distribution analysis
- Category/Product line wise sales comparison
- Country wise sales performance
- Quantity ordered analysis
- Sales trend based on time (if date column is used)
- Profit/Sales relationship visualization (if available)

---

## Tools & Technologies Used
Python, Jupyter Notebook, Pandas, Matplotlib, Seaborn

---

## Learning Outcome
This task helped in understanding how visualizations can be used to analyze datasets, identify trends, compare categories, and interpret business performance.

---

## Conclusion
Sales data visualization helped in identifying important patterns such as top-performing product categories, high-sales regions, and overall sales distribution. These insights can support better business decision-making.
