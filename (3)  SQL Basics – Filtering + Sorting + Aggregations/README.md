# Sales Data Analysis using SQL (Task 3)

## Aim
To analyze sales data using SQL queries and generate summary results for business insights.

---

## Dataset Used
**Sales Dataset**

The dataset contains sales transaction details such as product information, quantity, sales amount, and other related fields used for analysis.

---

## Files in This Folder
- **sales_data_sample.csv** – Original sales dataset used for SQL analysis
- **queries_task3.sql** – SQL queries written for data analysis and summary generation
- **sales_summary.csv** – Output summary file generated after executing SQL queries

---

## Work Done in This Task
- Imported the sales dataset into a database table
- Performed data exploration using SQL queries
- Applied filtering, sorting, and grouping operations
- Used aggregate functions such as SUM, COUNT, AVG, and MAX
- Generated summary results based on products, sales performance, and order details
- Exported the final output summary into a CSV file

---

## SQL Concepts Used
- SELECT statements
- WHERE conditions
- GROUP BY and ORDER BY
- Aggregate functions (SUM, COUNT, AVG)
- DISTINCT values
- LIMIT and sorting operations

---

## Tools Used
SQL (MySQL / SQLite / PostgreSQL)

---

## Learning Outcome
This task helped in understanding how SQL can be used for real-world data analysis and how query-based summaries support decision making.

---

## Conclusion
Sales data analysis using SQL queries provided useful insights and summary reports. The generated results can be used to understand sales trends and business performance.
