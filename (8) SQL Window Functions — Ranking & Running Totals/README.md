# E-Commerce Sales Analysis using Window Functions

## Aim
To analyze e-commerce sales data using SQL Window Functions and generate advanced insights such as customer ranking and month-on-month (MoM) sales growth.

---

## Dataset Used
**Ecommerce Sales Data 2024–2025**

This dataset contains transaction details such as customer purchases, order information, sales amount, and time-based data for the years 2024 and 2025.

---

## Files in This Folder
- **Ecommerce_Sales_Data_2024_2025.csv** – Raw dataset used for SQL analysis
- **task8_window.sql** – SQL queries implementing window functions
- **mom_growth.csv** – Output file containing Month-on-Month growth results
- **ranked_customers.csv** – Output file containing ranked customers based on sales/purchases
- **insights_task8.txt** – Text file containing summarized insights from analysis

---

## Work Done in This Task
- Imported the dataset into a database table
- Applied Window Functions to perform advanced SQL analysis
- Generated customer ranking reports
- Calculated Month-on-Month sales growth
- Extracted insights based on sales trends and customer performance
- Exported final outputs into CSV format for reporting

---

## SQL Concepts Used
- Window Functions
- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- PARTITION BY
- ORDER BY within window functions
- Aggregations with OVER()
- Month-on-Month comparison

---

## Tools Used
SQL (MySQL / PostgreSQL / SQLite), CSV Export

---

## Learning Outcome
This task helped in understanding how window functions simplify ranking, trend analysis, and time-based comparisons in SQL.

---

## Conclusion
Window functions were successfully used to generate meaningful business insights such as top customer ranking and month-on-month growth analysis. The output reports provide clear understanding of sales trends and customer contribution.
