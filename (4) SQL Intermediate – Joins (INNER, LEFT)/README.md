# E-Commerce Data Analysis using SQL Joins

## Aim
To perform analysis on an e-commerce dataset using SQL JOIN operations and generate meaningful outputs by combining related data.

---

## Dataset Used
**Ecommerce Dataset**

The dataset contains customer and order-related details used for SQL query analysis and join operations.

---

## Files in This Folder
- **Ecommerce_data_1000.csv** – Raw dataset used for SQL join analysis
- **joins_queries.sql** – SQL queries implementing different JOIN operations
- **Joined_Outputs.xlsx** – Output results generated after executing JOIN queries
- **insights.txt** – Key findings and insights from the join analysis

---

## Work Done in This Task
- Imported the dataset into a database table
- Performed data exploration using SQL
- Applied JOIN operations to combine related data
- Generated final joined results for analysis
- Exported query outputs into Excel format
- Documented insights based on the results

---

## SQL Concepts Used
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL JOIN (if supported)
- Aliases
- Filtering using WHERE clause
- GROUP BY and ORDER BY
- Aggregate functions (SUM, COUNT, AVG)

---

## Tools Used
SQL (MySQL / SQLite / PostgreSQL), MS Excel

---

## Learning Outcome
This task helped in understanding how JOIN operations are used to combine tables and generate meaningful business reports from relational data.

---

## Conclusion
SQL JOIN operations were successfully applied on the e-commerce dataset to generate combined outputs and insights. The results help in understanding relationships between customer, product, and order data.
